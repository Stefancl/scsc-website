# SCSC Website

Launch website for **SCSC — See. Capture. Share. Connect.**

A lightweight, responsive single-page website for Sonia's Cape Winelands photography business.

## Positioning

Warm, natural, accessible-premium lifestyle photography across Somerset West, Stellenbosch, Franschhoek and Cape Town.

## Current sections

- Hero / brand proposition
- SCSC philosophy
- Portfolio/story categories
- Photography experiences and starting prices
- Founding Five launch offer
- About Sonia
- WhatsApp-first booking CTA

## Before publishing

1. Replace the placeholder WhatsApp number in `script.js` with Sonia's number in international format.
2. Replace all temporary Unsplash imagery with Sonia's own portfolio photographs as soon as the three launch portfolio shoots are complete.
3. Review prices before public launch.
4. Add privacy/booking terms once finalised.

## Local preview

Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8080
```

Then browse to `http://localhost:8080`.

## Hosting

This static site can be hosted on GitHub Pages, Cloudflare Pages, Netlify, Vercel or a normal web host for `scsc.co.za`.
